# Next.js App Router starter

Country autocomplete with [`@autosugges/client`](https://www.npmjs.com/package/@autosugges/client).

```sh
npx degit autosugges/autosugges-js/examples/nextjs-app-router nextjs-app-router
cd nextjs-app-router
cp .env.example .env.local   # then set NEXT_PUBLIC_AUTOSUGGES_KEY
npm install
npm run dev
```

Get a free key at https://app.autosugges.com (`pk_live_...`, safe in a browser) and put it in `NEXT_PUBLIC_AUTOSUGGES_KEY`.
