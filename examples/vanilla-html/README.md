# Vanilla HTML starter

Country autocomplete with one script tag and no build step.

```sh
npx degit autosugges/autosugges-js/examples/vanilla-html vanilla-html
cd vanilla-html
# edit index.html: replace YOUR_PUBLISHABLE_KEY, then
npx serve .
```

Get a free key at https://app.autosugges.com (`pk_live_...`, safe in a browser).
