# Expo starter

Country autocomplete with [`@autosugges/client`](https://www.npmjs.com/package/@autosugges/client).

```sh
npx degit autosugges/autosugges-js/examples/expo expo
cd expo
cp .env.example .env   # then set EXPO_PUBLIC_AUTOSUGGES_KEY
npm install
npx expo start
```

Get a free key at https://app.autosugges.com (`pk_live_...`, safe in a browser) and put it in `EXPO_PUBLIC_AUTOSUGGES_KEY`.
