# Vite + React starter

Country autocomplete with [`@autosugges/client`](https://www.npmjs.com/package/@autosugges/client).

```sh
npx degit autosugges/autosugges-js/examples/vite-react vite-react
cd vite-react
cp .env.example .env   # then set VITE_AUTOSUGGES_KEY
npm install
npm run dev
```

Get a free key at https://app.autosugges.com (`pk_live_...`, safe in a browser) and put it in `VITE_AUTOSUGGES_KEY`.
